# ReminedPacks

Game pack releases for [ReminedLauncher](https://github.com/LAYT73/ReminedLauncher).

- Pack artifacts ship as **GitHub Releases** (zip + `manifest.json`).
- This repo tracks the latest manifest and pack notes — not the binary zip in git history.

## VanillaPro cleanup rules

Removed from releases: `saves/`, `screenshots/`, `logs/`, `crash-reports/`, `natives/`, caches (`.cache`, `.mixin.out`, `.fabric`, `usercache.json`), `TLauncherAdditional.json`, empty temps.

Kept: `mods/`, `config/`, `resourcepacks/`, `shaderpacks/`, `options.txt`, `Notebook/`, `bivrik/`, `data/`, `frozenlib/`, jars/json, `defaultconfigs/`.
